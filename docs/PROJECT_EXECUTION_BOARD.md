## 2. 严重度与状态

### 严重度

- `P0`：无法开始、无法继续、存档损坏、序幕身份不可理解、朝议无法退出/继续、重大历史人物凭空登场、正式音视频无法使用、发布签名/版本错误。存在未关闭 P0 时不得发布。
- `P1`：功能可进入但明显违背皇帝模拟定位，例如对话僵硬、召见不合理、地图方向错误、NPC 无法形成真实行动、交互误触严重。必须修复、明确降级或由项目负责人接受。
- `P2`：美术丰富度、长期扩容、额外动画、非核心性能优化等后续事项。

### 状态

- `NEXT`：唯一当前下一执行项。
- `TODO`：已排期，但没有开始。
- `IN_PROGRESS`：已声明负责人、分支和受保护文件。
- `NEEDS_REPRO`：玩家已反馈，尚缺确切版本、步骤或定位证据。
- `DEVICE_REQUIRED`：已有代码/资源/自动证据，但缺真实手机验收。
- `BLOCKED`：存在明确外部阻塞，并写明解除条件。
- `DONE`：代码、自动回归、构建、必要资源和对应人工验收全部完成。
- `DEFERRED`：经项目负责人批准延期，写明原因与目标版本。

用户反馈只能在复现后调整严重度；无法复现也要记录 APK、设备、模型、中转配置、网络状态、输入与截图。

## 4. 历史人物与程序生成人物的边界

所有人物显示、召见、奏议、任命和战斗都应满足：

`出生/死亡 + 历史活动窗口 + 当前年份 + 当前官职 + 当前位置/旅行 + 势力归属 + 存活状态 + 玩家已改写历史`

- 已存在的史实人物：读取当前 `GameState`，不得用后世官职、默认画像台词或剧情名字覆盖真实履历。
- 史料未明确的普通人：可以由后续系统生成，但须有 `generated` 来源、稳定 ID、生成时间、地域、所属势力、官职约束和存档记录。
- “召临安知府”：先检查当前城市归属、现任官员和是否可被召见；无人任职时只能按已批准的补位规则创建合乎时代的普通官员，不能把 1127 临安说成既定首都。
- “枢密院拟三套北伐方案”：先验证机构、负责人、情报、预算和现有军团；方案只是建议，所有调兵、开战、募兵和花费仍需正式授权与本地规则。
- 未出生、已死亡、被俘、身处敌营、未赴任或远在前线的人不得突然出现在应天朝会。

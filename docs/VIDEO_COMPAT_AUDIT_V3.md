# 《南渡无悔》V3 视频兼容审计 — 2026-08-20

## 审计结果

对已成功构建 APK 中的 V3 视频资产执行 `ffprobe` 全量扫描：

- 总视频：51
- HEVC / H.265：51 / 51
- 带 AAC 音轨：51 / 51
- H.264：0 / 51
- 无音轨：0 / 51
- 1280×720：41
- 720×960：9
- 834×1112：1
- 平均时长：约 4.71 秒
- 最短：约 1.79 秒
- 最长：约 20.21 秒

这解释了两个风险：

1. 部分 Android 设备无法稳定硬解 HEVC。
2. 生成器残留 AAC 音轨可能与游戏的 BGM / Voice / Ambience 同时播放，造成刺啦、杂音或不受控人声。

## 当前运行时保险

`AssetVideoSurface` 已改为强制静音；即使旧调用显式传 `muted=false`，也不会放出 MP4 内嵌音轨。

序章使用的独立 `VideoView` 同样强制 `setVolume(0f, 0f)`。

## 发行清洗版

已对上述 51 条视频做无内容重制的兼容转码：

- H.264 / AVC
- `yuv420p`
- 保留原分辨率
- 保留原时长（允许编码器时间基微小差异）
- 完全删除音轨 `-an`
- `faststart`
- 画面内容不重新生成

清洗后验证：

- H.264：51 / 51
- 无音轨：51 / 51
- 验证错误：0
- 总体积约：56.3 MiB

## 最终替换策略

最终集成阶段应使用清洗版二进制替换旧 V3 MP4，保持相同相对路径和文件名，避免 Kotlin 路由改动。

Batch4 新视频从源头要求：H.264 + video-only MP4，不再重复这个兼容债务。

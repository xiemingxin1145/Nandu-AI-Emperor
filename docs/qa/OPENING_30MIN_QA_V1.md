## 一句话总评

**骨架已经像一款“建炎元年赵构模拟器”，但前30分钟仍更像“带历史皮肤的策略管理壳 + 半成品演出”。**

数据层（应天府行在、人物状态、在场过滤）比 UI 层和事件层更诚实。  
玩家眼睛看到的那一层，仍大量残留临安时代文案、固定三选一朝会、名人台词模板。

当前评分（导演主观）：

| 维度 | 分 |
|------|----|
| AI 原生完成度 | **38 / 100** |
| 历史沉浸感 | **52 / 100** |
| “像真正游戏”的程度 | **45 / 100** |

## 第一部分：完整开局流程逐步审查

### 1. 启动 APP → 主菜单

**看见什么**  
深色金边菜单；可有动态视频背景（若资产可用）；入口含新游戏 / 继续 / 设置，另有“天命绘卷”作视频资产验收入口。

**能做什么**  
点新游戏、继续、设置、退出；可进天命绘卷刷视频。

**困惑 / 无聊 / 不像游戏**  
- “天命绘卷”对玩家像开发者工具，不像皇帝身份的入口。  
- 主菜单 BGM / 动效若缺失，第一印象偏工程包而非成品。

**代入感**  
标题与色调有一点南宋沉郁，但还不够“官家将启程”。

---

### 2. 序章六幕

| 幕 | 玩家看见 | 评价 |
|----|----------|------|
| 一 · 山河将倾 | 金军南下 CG + 旁白 | 氛围成立；BGM 白名单为空，音场偏空 |
| 二 · 靖康之变 | 围城 CG/视频 + 旁白 | 最强历史冲击；视频内嵌音静音规则正确 |
| 三 · 宋室南渡 | 应天即位叙述 | **正确写南京应天府、改元建炎** |
| 四 · 旧史已成 | 军议感画面 | “未来不再只有一条路”——主题对，演出偏静 |
| 五 · 我成了赵构 | 铜镜/身份 CG | **核心爽点候选**：穿越落点清晰 |
| 六 · 百官候朝 | 殿外内侍：“候在**垂拱殿**” | **历史穿帮/时代错位风险**（见穿帮文档） |

**困惑**  
第六幕用“垂拱殿”作开局主殿名，玩家会默认自己在临安宫城，与第三幕应天府冲突。

**无聊**  
六幕总时长约 90 秒量级，节奏尚可；缺 BGM 时易成“静音 PPT”。

**最有代入感**  
第五幕“我成了赵构”。

---

### 3. 进入应天行在 → 第一次朝会

**看见什么**  
皇宫主页 / 宫殿入口（内部仍大量 `chuigong` id）；朝会议题为固定 `CouncilScene`（主战/南幸、军议、钱粮等）；台词经 `CharacterAppearanceSystem.filterCouncilLines` 过滤不在场者。

**能做什么**  
选宫殿、看议题、在 2～3 个固定选项里下旨；可点人物、地图、军务等系统入口。

**困惑**  
- 数据首都是应天，UI/结果文案仍常写“垂拱殿定……”。  
- 朝会像“读三段立场 + 点一个按钮”，不像群臣争锋。

**不像游戏**  
选项结果多为数值条变化说明，缺少当场人物表情/派系即时反应演出。

**代入感**  
李纲 vs 黄潜善/汪伯彦 的路线分歧**内容正确**，是建炎初政该有的题；呈现方式仍偏表格。

---

### 4. 查看人物 / 地图 / 军务

**人物**  
状态机（WANDERING / NOT_YET_RELEVANT / CAPTIVE / IN_CAPITAL）方向正确；详情若暴露“解锁”“尚未进入本局视野”等开发者句式，沉浸会破。

**地图**  
城池数据：杭州、越州命名在 `InitialData` 正确；但 `MapData` 节点仍标「临安」且 `isCapital=true`，与应天府行在冲突 → 玩家第一眼地图可能误判首都。

**军务**  
金军在开封/大名/太原有实体军团；战略脑 `FactionStrategyPlanner` 存在。前30分钟玩家是否**看见**金军在动，取决于回合推进与战报 UI，目前更像“点过旬才结算”的策略回合，而非持续压迫感。

---

### 5. 第一道旨意 → AI 群臣反应 → 过第一旬

**旨意**  
存在自由输入圣旨路径与 Mock/外部 Provider；前30分钟若走固定朝会选项，几乎感觉不到“AI 群臣”。

**过旬**  
日历建炎元年六月设定正确；宗泽 `scheduledTurn` 外任设计是亮点，但需在 UI 明确“宗泽离京赴东京留守”，否则玩家只看到名单少一个人。

**第二轮世界反馈**  
若只有数值变动日志、没有军报/邸报/人物主动奏事，世界会“死”。

## 前30分钟情绪曲线（导演判断）

```
启动        序章2-3     第五幕      进朝会      第一道旨      过旬
 平    →   高(历史) →  高(身份) →  中低(表格) → 低(选项) → 低/中
```

**断裂点**：第五幕结束后，没有“我真的在应天府第一次坐殿”的仪式感，直接掉进管理 UI。

---

## 与“AI 原生南宋皇帝游戏”的差距（开局视角）

已有：

- 世界状态权威、模型不能瞬移军队  
- 人物在场规则、知识边界（本基线已修）  
- 金国势力战略候选  

仍缺：

- 开局即感到“金军在动、朝臣在争、你在抉择”的**同屏反馈**  
- 非名人官员承担递奏/封驳/传旨的戏份  
- 玩家决定被朝臣**记住并在下一旬提起**

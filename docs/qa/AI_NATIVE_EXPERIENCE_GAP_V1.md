# AI 原生体验缺口审查 V1

问题：**AI 是否在操控整个世界，还是只在传统手游壳上挂了聊天框？**

---

## 一、已经有 AI 原生感的部分

| 能力 | 证据 | 玩家前30分钟能否感知 |
|------|------|----------------------|
| 世界状态权威 | 模型动作经 WorldAiTurnExecutor 校验，不能瞬移 | 弱（除非看战报） |
| 势力战略脑 | FactionStrategyPlanner 威胁→候选→评分 | 弱 |
| 人物在场/知识边界 | CharacterStateSource / visibleToWorldAi | 间接（少穿帮） |
| 圣旨自由文本 | ViewModel + Provider 管线 | 强（若玩家尝试） |
| 人物 Agent 状态结构 | CharacterAgentState 序列化、目标字段 | 弱（主动提案未成开局戏） |
| 宗泽定时外任 | scheduledTurn | 中（需 UI 说明） |

这些是**后端原生**；前30分钟多数时候玩家摸不到。

---

## 二、仍像传统手游壳的部分

1. **朝会 = 固定 3 选项**（CourtCouncilSystem 预写场景）
2. **NPC 主要等你点**
3. **敌人主动行为不可见**
4. **记忆与派系未变成台词**
5. **随机事件临安时代文案**
6. **AI 设置暴露偏工具箱**

---

## 三、评分说明（38/100）

引擎在长 AI 原生的骨头；前30分钟皮肤仍是传统策略手游。
导演要求：**先让玩家在 10 分钟内看见世界在动，再谈更强模型。**

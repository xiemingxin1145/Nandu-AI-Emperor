# 第一次正式朝会 · 导演方案

**时间**：建炎元年六月  
**地点**：南京应天府行在正殿（避免「临安垂拱殿」）  
**目标**：10 分钟内感到大宋危急、朝臣分裂、北方压力、决定有重量；保留自由决策。

## 出场阵容

历史人物 3～4：李纲、宗泽、黄潜善、汪伯彦。  
岳飞/秦桧/赵鼎/吴玠/刘锜不出场。韩世忠不站文班。  
普通官员至少 3：韩德裕（军报）、周彦章（封驳）、张继恩（传宣）。

## 三拍

1. 家底奏报（兵粮敌情量级）
2. 走还是守（主战 vs 南幸，小官可程序异议）
3. 突发军情（情报可不完全准，逼决策）

## 结束钩子

邸报金军动态、宗泽将赴东京、未决兵籍或粮道之一。

## 爽点

一句话定调有人再拜；点名小官下旬真来；给事封还形成程序张力。
禁止十连抽与神将空降。

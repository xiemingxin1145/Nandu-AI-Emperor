# 《南渡无悔》BGM 第二批接入记录

本批音频由用户提供生成音乐后，经 ChatGPT 拆分、统一响度并制作循环衔接。

计划接入 `app/src/main/assets/audio/bgm/`：

- `bgm_chuigong_hall_loop.ogg`：垂拱殿常驻循环
- `bgm_chuigong_hall_entry.ogg`：垂拱殿入殿/升朝演出
- `bgm_garden_loop.ogg`：后苑/御花园
- `bgm_study_loop.ogg`：御书房
- `bgm_worldmap_loop.ogg`：天下地图
- `bgm_linan_loop.ogg`：临安城/城市
- `bgm_military_camp_loop.ogg`：军营/军务

接入原则：保留现有旧 BGM 文件作为回退，不直接删除；新场景路由优先使用本批新 BGM。

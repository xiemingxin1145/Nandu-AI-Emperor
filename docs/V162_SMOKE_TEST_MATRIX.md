## 结果定义

- `AUTO`：已有 JVM 单测、源码守卫、构建守卫或 APK 拆包检查；不等于手机点击已验证。
- `STATIC`：已检查代码与数据路径，但尚无覆盖该入口的自动操作。
- `DEVICE`：必须由真实 Android 手机完成交互、播放或系统返回验证。
- `BLOCKED`：预验收已识别明确缺陷或资源缺口，不能以 CI 全绿冒充通过。
- `WAIT-006`：必须等待 Claude 的 STAB-006 分支合入后重跑。
- `N/A`：该入口不应存在空白状态；若出现，视为失败。

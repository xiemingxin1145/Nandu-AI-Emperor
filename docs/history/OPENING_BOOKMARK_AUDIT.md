## 正式推荐开局日

**建炎元年六月己未朔（推荐钉死为：建炎元年六月初一日）**

| 项 | 值 |
|---|---|
| **公历** | **约 1127 年 7 月 11 日** |
| **宋代年号** | 建炎元年六月 |
| **农历** | 六月己未朔（六月初一） |
| **皇帝所在地** | **南京应天府**（河南商丘，非杭州） |
| **宫廷环境安全称呼** | **应天行在·内殿**。史料当日明确有“入见于内殿”；不应把未经充分证据的建筑名写死，更不能套用后来临安垂拱殿 |
| **为何最适合游戏** | ① 赵构已即位，法统成立；② 李纲当日抵达行在并入见；③ 黄潜善、汪伯彦与主战派路线冲突已具备爆发条件；④ 宗泽当日也在南都入对，随后即将外任，天然形成状态迁移演出；⑤ 岳飞不是朝堂重臣；⑥ 秦桧仍在金营；⑦ 玩家可以真正改变李纲去留、宗泽外任、还汴/南幸、两河经营等未来历史。 |

## 十问简答（本审计范围）

1. **正式开局哪天最好？** → 建炎元年六月己未朔（约 1127-07-11），应天府。  
2. **赵构当时在哪里？** → 南京应天府（商丘）。  
3. **能否称临安？** → **不能**。杭州升临安府在建炎三年（1129）；1127 开局更不能把“临安”当南宋既成都城。  
4. **适合用垂拱殿吗？** → **不适合**。临安垂拱殿属于绍兴十二年前后宫城建置；1127 应天开局应使用“应天行在·内殿”等史料安全称呼。  
5. **宗泽开局在哪？** → **开局当天在南都并入对**；不能第一帧就写成已经常驻东京。随后才外任并转东京留守。  
6. **李纲开局在哪？** → 当日刚抵达行在并入见。  
7. **岳飞能否列普通朝班？** → 不能。建炎元年五月上书后被夺官，八月再投张所。  
8. **秦桧能否在朝？** → 不能，建炎四年十月南归前仍在金方控制体系。  

其余人物见 `CHARACTER_LOCATIONS_1127.md`。

## 主要依据

- 《建炎以来系年要录》卷六：**“建炎元年六月己未朔”**，李纲至行在并“入见于内殿”；同日宗泽以数百骑赴南都，“是日入对”。  
- 《宋史·高宗本纪》：建炎元年五月庚寅即位、建炎初任免。  
- 《金佗稡编》卷四：岳飞建炎元年五月上书后被夺官，八月投河北招抚使张所。  
- 秦桧建炎四年十月南归的纪年材料。  
- 《咸淳临安志》卷一：杭州州治建炎三年二月为行宫，绍兴十二年建垂拱殿。  

公历日期用于现代玩家理解；若换算资料出现一日左右差异，游戏内仍以“建炎元年六月己未朔”为首要 Canon 锚点。

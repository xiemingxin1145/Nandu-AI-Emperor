## 正式推荐开局日

**建炎元年六月己未朔前后（推荐钉死为：建炎元年六月初一日）**

| 项 | 值 |
|---|---|
| **公历** | **约 1127 年 7 月 11 日**（据常见农历对照：建炎元年六月己未 → 7/11） |
| **宋代年号** | 建炎元年六月 |
| **农历** | 六月己未朔（六月初一） |
| **皇帝所在地** | **南京应天府**（河南商丘，非杭州） |
| **宫廷环境** | 应天**府治正厅**权充殿宇；无北宋汴京大内，无临安行宫 |
| **为何最适合游戏** | ① 赵构已即位，法统成立；② 李纲已至行在，可作主战相；③ 黄潜善、汪伯彦主和线对立；④ 宗泽将赴东京留守，两河未死；⑤ 岳飞尚非朝堂人物，避免名将开局刷脸；⑥ 秦桧仍在金营，不可能上朝；⑦ 玩家改变历史的空间最大（还是走还汴、还是幸东南、用谁相）。 |

即位当天（A）只适合 CGI 序章；**玩法开局应落在 B**。

## 十问简答（本审计范围）

1. **正式开局哪天最好？** → 建炎元年六月初一前后（约 1127-07-11），应天府。  
2. **赵构当时在哪里？** → 南京应天府（商丘）。  
3. **能否称临安？** → **不能**。杭州升临安府在建炎三年（1129）；行在语境稳定更晚。  
4. **适合用垂拱殿吗？** → **不适合**。建炎元年无此殿于应天；临安垂拱殿约绍兴十二年后才有规模。应用「府治正厅 / 行在便殿 / 御衙」等。  

其余人物见 `CHARACTER_LOCATIONS_1127.md`。

## 主要依据

- 《建炎以来系年要录》卷五：五月庚寅即位应天府治正厅；六月李纲至行在  
- 《宋史·高宗本纪》：五月庚寅即位改元；六月以李纲为相相关纪事  
- 《三朝北盟会编》炎兴下帙：即位仪注  
- 维基「建炎」农历对照表（五月庚寅 → 1127-06-12；六月己未 → 1127-07-11）  
- 临安府建置：建炎三年升杭州为临安府；绍兴八年定行在  
- 临安宫室：绍兴十二年前后始作崇政、垂拱等殿（李心传记述）

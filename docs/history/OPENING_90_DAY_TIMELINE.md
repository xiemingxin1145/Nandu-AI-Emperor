# OPENING_90_DAY_TIMELINE.md

窗口：**开局前 30 天 + 开局后 60 天**  
开局钉：**建炎元年六月初一 ≈ 1127-07-11**，行在应天府

分类：
- **FIXED_PAST** — 已发生，玩家不可改
- **HISTORICAL_PRESSURE** — 历史惯性强，可部分改写代价极高
- **BUTTERFLY_CHANGEABLE** — 允许玩家改变

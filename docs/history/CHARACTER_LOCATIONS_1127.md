## 人物表（开局日）

### 赵构（宋高宗）
- alive: true；年龄约 21（虚岁）
- 身份: 皇帝（建炎）
- 所在: **南京应天府**
- 可见性: AT_COURT（玩家本体）
- 关系: 新君，依赖黄/汪，亦不得不借李纲声望

### 李纲
- alive: true；约 45 岁
- 身份: **尚书右仆射兼中书侍郎**（右相，五月召、六月至）
- 所在: 应天府行在
- 在朝: **是**；可参加朝会
- 可见性: **AT_COURT**
- 阶段: 主战相，与黄潜善、汪伯彦对立；历史约八月罢相（相位仅约 75 日）
- 未来节点: 罢相、贬谪、绍兴后再起于地方

### 宗泽
- alive: true；约 69 岁
- 身份: 由知襄阳改 **东京留守、知开封府**（六月前后落实）
- 所在: **开封（东京）** 或赴任途中
- 在朝: **否**（不在应天日常朝会）
- 领军: 是（留守司）
- 可见性: **DEPLOYED**
- 与赵构: 力请还京，疏奏多；被黄/汪排挤出朝
- 未来: 建炎二年病逝开封，临终呼「过河」

### 岳飞
- alive: true；**25 岁**
- 身份: 低阶武官；即位后曾**越职上书请回銮，被罢军职**（建炎元年）
- 所在: **不在行在朝堂**；河北/京东军中或待再从军（八月投张所帐前）
- 在朝: **否**
- 可征辟: 可作为**军中低阶/传闻人才**，不可开局即列殿
- 可见性: **WANDERING / UNKNOWN_TO_EMPEROR**（皇帝知其名的概率极低）
- **硬规则: 绝不能因后世名气出现在普通朝会**
- 未来: 张所→王彦→宗泽部下→渐起

### 韩世忠
- alive: true；约 39 岁
- 身份: **光州观察使、带御器械**；御营司系统将领（左军统制一类）
- 所在: 行在周边，扈从力量
- 在朝: 武职近臣，**可在军务场合出现**；非常朝文班
- 可见性: **IN_CAPITAL** 或受限 AT_COURT（武臣路径）
- 未来: 中兴名将，江上作战

### 张浚
- alive: true；约 30 岁
- 身份: 建炎初自京师至，曾摄太常礼仪相关；尚未是后来的宣抚宰相
- 所在: 行在
- 可见性: **IN_CAPITAL**（中低阶文臣起步）
- 未来: 御史弹李纲等，后掌兵与相业

### 赵鼎
- alive: true
- 开局时: **尚未进入建炎核心决策圈**（成名与相业在绍兴）
- 可见性: **NOT_YET_RELEVANT** 或 LOCAL_OFFICIAL
- 不可开局当宰执脸

### 秦桧
- alive: true
- 身份: 原御史中丞；**靖康被俘北去**
- 所在: **金国**（赐挞懒/完颜昌，后为任用）
- 在朝: **否**
- 可见性: **CAPTIVE**（对宋廷为失踪/北俘）

### 吴玠 / 刘锜
- 开局: 西北/军中中低阶或未显达

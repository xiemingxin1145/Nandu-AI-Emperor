# CHARACTER_LOCATIONS_1127.md

开局日基准：**建炎元年六月己未朔（约 1127-07-11）**，行在：**南京应天府**。

可见性标签供后续 `CharacterStateSource` 使用：  
`AT_COURT | IN_CAPITAL | DEPLOYED | LOCAL_OFFICIAL | WANDERING | UNKNOWN_TO_EMPEROR | ENEMY | CAPTIVE | RETURNING | NOT_YET_RELEVANT`

> Canon v1.1 校审说明：开局日必须按“六月己未朔当天”处理。此日《建炎以来系年要录》明确记载李纲至行在，宗泽亦以数百骑赴南都并“是日入对”。因此宗泽不能在开局第一帧就直接写成“已在东京留守任上”；正确做法是：开局当天短暂 `AT_COURT`，随后根据历史压力外任，之后才进入东京留守阶段。

## 给 Claude / CharacterStateSource 的最小集合

开局 `AT_COURT` 核心：赵构（玩家）、李纲、黄潜善、汪伯彦。  
开局当天特殊 `AT_COURT`：宗泽（当日入对，之后应触发外任状态迁移）。  
开局 `IN_CAPITAL`：张浚、韩世忠（后者仅军务场合受限出现）。  
开局 `CAPTIVE`：秦桧。  
开局 `WANDERING / UNKNOWN`：岳飞。  
开局 `NOT_YET_RELEVANT`：赵鼎、吴玠、刘锜。

**状态迁移硬要求：**宗泽不能从第一帧就锁成东京留守，也不能因为开局当天入对而永久留在皇帝身边；应由时间/事件把他从 `AT_COURT` 推向外任 `DEPLOYED`。
